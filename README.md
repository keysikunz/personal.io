## How to activate the site (1 minute)

1. Go to: [Repository Settings → Pages](https://github.com/keysikunz/personal.io/settings/pages)
2. Under **Source** select:
   - Branch: `main`
   - Folder: `/ (root)`
3. Click **Save**
4. Wait 30–60 seconds and open the link above.

---

## Adding the photos

1. Click **Add file → Upload files**
2. Create / go into the `images` folder
3. Drag all your photos and rename them exactly as:
   - `club-face.jpeg`
   - `cyber-city.jpeg`
   - `pole-leather.jpeg`
   - `pink-bunny.jpeg`
   - `pool-table.jpeg`
   - `cat-ears.jpeg`
   - `pole-blue.jpeg`
   - `red-top.png`
   - `nude-portrait.jpg`
   - `pink-hair.jpeg`

Then the full gallery will appear.
